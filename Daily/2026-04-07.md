## Notes

### App-Interface GraphQL Schema Research
- Endpoint: `https://app-interface.apps.rosa.appsrep09ue1.03r5.p3.openshiftapps.com/graphql`
- Query: `apps_v1` returns `App_v1` objects with a `codeComponents` field
- `codeComponents` (`AppCodeComponents_v1`) has:
  - `name` - component name
  - `url` - **git repository URL** (the key field we need)
  - `resource` - type: `upstream`, `bundle`, `gitops`, `infrastructure`, `other`
  - `mirror`, `imageBuildUrl` - additional context
- Schema source: `qontract-schemas` repo, `graphql-schemas/schema.yml` (lines ~2877-2892 for `AppCodeComponents_v1`, ~2937-3016 for `App_v1`)
- Plan: new `cve-resolve` stage sits between `cve-enrich` and `cve-report`, takes enriched JSON, queries app-interface for matching app names, attaches `code_components` to each ticket
- Future: these repo URLs will be used to spin up agents that scan the actual codebases to assess upgrade risk and breaking changes
