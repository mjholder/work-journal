### Project: RHDH 1.9 Upgrade
**Current focus:** Investigating plugins removed from RHDH 1.9 image

**Roadiehq plugins investigation:**
- Found that roadiehq plugins still exist in the roadiehq project
- **Problem:** They are NOT dynamic plugins in their original repos (they were dynamic when packaged with RHDH)
- Cannot use them directly from roadiehq repos since we need dynamic plugin format

**RHDH intentionally dropped community plugin wrappers:**
- Found PR that explains the removals: https://github.com/redhat-developer/rhdh/pull/3960
- **32 community wrapped plugins deleted** including all the ones we're missing
- **Reason:** RHDH wants to drop support for "community" plugin wrappers to avoid the whole patching process on upgrades
- Community plugins should be maintained in community-plugins repo and roadiehq has their own repo

**Next steps - evaluate impact:**
- Test RHDH 1.9 without these 6 plugins to see what functionality is lost
- Initial testing shows no obvious differences - plugins may not be heavily used
- Decide whether to invest effort in bringing plugins back (if even possible as dynamic plugins)
- May be simpler to just remove unused functionality

### Project: Backstage AppStage Entity Provider

Completed Apollo Client 4 migration and test fixes for `backstage-plugin-appstage-entity-provider`:
- **Runtime fix:** Added explicit `HttpLink` in client factory (Apollo 4 requires `link`; passing only `uri` left link undefined and caused "Cannot read properties of undefined (reading 'request')").
- **TypeScript (28 errors):** Removed generic `ApolloClient<NormalizedCacheObject>` everywhere (Apollo 4’s `ApolloClient` is not generic); replaced deprecated `createMockClient` with `MockLink` from `@apollo/client/testing` in all DAL and resolver tests; added `if (!data) return []` guards in resolvers for possibly undefined query data; fixed test destructuring for possibly undefined `data`.
- **Unit tests:** Fixed failing `resourceDAL.test.ts` and `componentDAL.test.ts` by using `variables: () => true` and `fetchPolicy: 'no-cache'` on the mock client, and stripping `__typename` from actual responses before equality checks so Apollo cache normalization doesn’t break assertions.
