### Deploying Updated Clowder Image to Minikube

**Context:** Fixed race condition bug in ClowdEnvironment status reconciliation (filters.go). Need to deploy new image to test the fix.

**Steps to Build and Deploy New Clowder Image:**

1. **Build the Docker image**
   ```bash
   make docker-build-no-test IMG=localhost:5000/clowder:latest
   ```
   - This builds the image with all current code changes
   - Uses podman to build the image locally

2. **Load image into minikube's Docker**
   ```bash
   eval $(minikube docker-env) && podman save localhost:5000/clowder:latest | docker load
   ```
   - Sets up minikube's Docker environment
   - Exports the image from podman and imports it into minikube's Docker

3. **Update kustomize configuration** (optional if using make deploy)
   ```bash
   cd config/manager && kustomize edit set image controller=localhost:5000/clowder:latest && cd ../..
   ```

4. **Deploy to cluster**
   ```bash
   make deploy IMG=localhost:5000/clowder:latest
   ```
   - This applies all the manifests to the cluster
   - Triggers a rolling update of the controller

5. **Wait for rollout to complete**
   ```bash
   kubectl rollout status deployment/clowder-controller-manager -n clowder-system --timeout=120s
   ```

6. **Verify deployment**
   ```bash
   kubectl get pods -n clowder-system -l control-plane=controller-manager
   kubectl describe pod -n clowder-system -l control-plane=controller-manager | grep -A 3 "Image:"
   ```
   - Check that pod is running
   - Verify it's using the correct image (localhost:5000/clowder:latest)

**Quick Reference (One-liner approach):**
```bash
make docker-build-no-test IMG=localhost:5000/clowder:latest && \
eval $(minikube docker-env) && podman save localhost:5000/clowder:latest | docker load && \
make deploy IMG=localhost:5000/clowder:latest && \
kubectl rollout status deployment/clowder-controller-manager -n clowder-system
```

**Common Issues:**
- **"connection refused" to registry** → Use the `eval $(minikube docker-env) && podman save | docker load` approach instead of pushing to registry
- **Old pod still running** → Force delete: `kubectl delete pod -n clowder-system -l control-plane=controller-manager`
- **Image not found in minikube** → Re-run the load step and verify with: `eval $(minikube docker-env) && docker images | grep clowder`
