### Dependabot PR Consolidation — Process & Lessons Learned

**Approach: diff-and-apply**
For each repo: clone → create `chore/consolidated-dependency-bumps` branch → apply each dependabot branch's diff (excluding `yarn.lock`) via `git diff origin/main...origin/<branch> -- . ':!yarn.lock' | git apply --3way` → commit after each → `yarn install` to regenerate `yarn.lock` → squash into single commit → push & create PR → close individual dependabot PRs.

**Apply order matters:**
1. GitHub Actions PRs first (touch `.github/workflows/` only — zero conflict risk)
2. Backstage group PR next (largest diff, touches most `package.json` files)
3. Other grouped PRs (testing, typescript)
4. Individual package bumps (patch/minor before major)

**Common version bumps across all repos (expect to see these repeatedly):**
- **backstage group** — 56 updates, touches root + `packages/app` + `packages/backend` + `plugins/*/package.json`
- **testing group** — `@jest/environment-jsdom-abstract`, `@playwright/test`, `jest`
- **typescript group** — TypeScript 5→6
- **actions/checkout** 4→6, **actions/setup-node** 4→6, **actions/upload-artifact** 4→7, **codecov/codecov-action** 4→6
- **@patternfly/react-core** 5→6, **@janus-idp/cli** 1→3, **prettier** 2→3, **node-gyp** 10→12

**Conflict patterns to watch for:**
- The **backstage group** changes context lines that later PRs (testing group, graphql, janus-idp/cli) rely on → `--3way` usually handles it, but `packages/app/package.json` and `plugins/*/package.json` needed manual resolution
- Conflicts leave `<<<<<<< ours` / `>>>>>>> theirs` markers in `.json` files — use python `json.loads()` to validate, then resolve by keeping "ours" versions (from backstage group, which are newer) plus the specific bump from "theirs"
- After resolving, validate JSON with `python3 -c "import json; json.load(open('package.json'))"`

**Yarn version split:**
- `backstage-plugin-openshift` and `backstage-plugin-visual-qontract` use **Yarn Classic (1.22.22)**
- All other repos use **Yarn Berry (4.4.1)** with `nodeLinker: node-modules`
- Both: `yarn install --no-immutable` regenerates `yarn.lock`

**Default branch varies:**
- `main`: openshift, cpt, ibutsu, kafka-info, ai-search-frontend, redhat-ai-project-space
- `master`: visual-qontract, progressive-delivery, firelink, metrics-and-monitoring
